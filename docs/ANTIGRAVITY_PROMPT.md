# Konteks untuk melanjutkan portofolio

Saya Satya Widnyana. Saya membuat web dengan bantuan AI dan ingin melanjutkan prototipe portofolio dalam folder ini. Baca `README.md`, `index.html`, `styles.css`, dan `script.js` terlebih dahulu. Gunakan `design-reference.html` sebagai acuan visual rancangan sebelumnya.

Pertahankan arah desain berikut:

- Editorial yang clean: monokrom, aksen merah anggur, tipografi besar, ruang lega, serta tampilan yang nyaman di mobile.
- Animasi halus dan ringan, tanpa efek berlebihan.
- Intro sekitar 5,6 detik dengan urutan **Hello → Bonjour → 你好 → こんにちは → Halo → “welcome to my portofolio” → cover**. Pertahankan ejaan kalimat itu sesuai permintaan saya sampai saya meminta perubahan.
- Tombol lewati intro, dukungan *prefers-reduced-motion*, serta tata letak responsif.
- Profil yang jujur tentang proses berbantuan AI; arah sebutannya **AI-assisted Web Creator**.

Foto, dua proyek, dan kontak masih placeholder. Jangan mengarang foto identitas saya, kredensial, pengalaman, jumlah klien, proyek nyata, testimoni, atau kontak. Minta informasi yang benar ketika dibutuhkan untuk menggantinya.

Folder ini adalah ekspor prototipe HTML/CSS/JavaScript biasa, tanpa npm atau build. Kontrol Mobile/Desktop/Putar intro digunakan untuk meninjau desain. Ubah prototipe menjadi website final hanya bila saya memintanya; jangan menganggap kontrol pratinjau harus menjadi bagian dari situs final. Jangan memublikasikan atau mengganti teknologi tanpa arahan saya.

Mulai dengan memahami file yang ada dan mengikuti perubahan yang saya minta berikutnya. Pertahankan gaya visualnya saat mengembangkan bagian baru, lalu cek tampilan mobile dan desktop, navigasi, intro, serta *reduced motion* setelah perubahan yang relevan.
