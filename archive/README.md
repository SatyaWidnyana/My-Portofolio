# Arsip project

File arsip disimpan untuk referensi dan pemulihan, tidak digunakan halaman utama.

- `baseline/`: source commit `683dd5d` sebelum refactor.
- `math-hover/`: backup eksperimen hover.
- `experiments/`: CSS dan lanyard lama.
- `diagnostics/`: hasil pencarian dan diff terdahulu.
- `references/`: rancangan referensi dan halaman ASCII.

HTML arsip bukan preview mandiri karena URL relatifnya masih mengikuti struktur awal. Edit `index.html` di root dan `assets/` untuk mengubah website aktif.
